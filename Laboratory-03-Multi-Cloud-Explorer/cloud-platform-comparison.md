# Cloud Platform Comparison

# AWS vs Microsoft Azure vs Google Cloud Platform

| Category | AWS | Microsoft Azure | Google Cloud Platform |
|---|---|---|---|
| Launch Year | 2006 | 2010 | 2008 |
| Compute Service | Amazon EC2 | Azure Virtual Machines | Compute Engine |
| Storage Service | Amazon S3 | Azure Blob Storage | Cloud Storage |
| Networking Service | Amazon VPC | Azure Virtual Network | Virtual Private Cloud (VPC) |
| Identity Service | AWS IAM | Microsoft Entra ID | Cloud IAM |
| Primary Strength | Wide range of cloud services | Microsoft and enterprise integration | AI, machine learning, and Kubernetes |
| Ideal Organizations | Startups, enterprises, and large organizations | Organizations using Microsoft technologies | AI, data, and cloud-native organizations |



### 1. Which cloud provider offers the broadest range of services?

For me, AWS has the widest variety of cloud services among the three. It offers many options for computing, storage, databases, networking, security, analytics, and artificial intelligence. Because of this, users have more choices when building different types of applications.

### 2. Which provider best integrates with Microsoft technologies?

I would choose Google Cloud Platform (GCP) for Artificial Intelligence, Machine Learning, and Kubernetes. Google has strong experience in these technologies and provides services such as Vertex AI and Google Kubernetes Engine (GKE). These tools can help developers build and manage modern applications.

### 3. Which provider is strongest in Artificial Intelligence and Kubernetes?

I would choose Google Cloud Platform (GCP) for Artificial Intelligence, Machine Learning, and Kubernetes. Google has strong experience in these technologies and provides services such as Vertex AI and Google Kubernetes Engine (GKE). These tools can help developers build and manage modern applications.

### 4. Which cloud platform would you personally choose and why?

Personally, I would choose AWS because it has many different services that can be used for different projects. I also like that it can support both small and large organizations. If the needs of a business increase, AWS resources can also be scaled to handle more users and workloads.

# Multi-Cloud Decision Matrix


| Business Requirement | Recommended Platform | Justification |
|---|---|---|
| Startup Company | AWS | I would recommend AWS because a startup can begin with only the resources it needs. As the business gets more customers, the cloud resources can also be increased. |
| Enterprise Organization | AWS |AWS is a good choice for a large organization because it offers many services that can support different business operations and applications. |
| Microsoft Environment | Azure | Azure would be my choice because it connects well with Microsoft products such as Windows Server, Microsoft 365, and Active Directory. |
| AI / Machine Learning | GCP |GCP is a good option for Kubernetes because it provides Google Kubernetes Engine (GKE), which helps users deploy and manage container-based applications.|
| Kubernetes Deployment | GCP | I would choose GCP for Kubernetes because it offers Google Kubernetes Engine (GKE). GKE makes it easier to deploy, manage, and scale applications that use containers. |
| Global Web Application | AWS |I would recommend AWS for a global web application because it has cloud infrastructure in many locations. It also provides services that can help handle changes in website traffic and keep the application available.|
