# Microsoft Azure Research

## Brief Overview

Microsoft Azure is a cloud computing platform created by Microsoft. It offers different cloud services that can be used for computing, storage, databases, networking, security, artificial intelligence, data analytics, and application development. Azure allows businesses and organizations to use these resources online without needing to manage everything using their own physical servers.

## Global Infrastructure

Azure has a global infrastructure with Regions and data centers located in different parts of the world. These regions allow companies to choose where their applications and data will be hosted. By choosing a location closer to their users, businesses can improve the performance, reliability, and availability of their applications.

## Cloud Management Console

The Microsoft Azure Portal is a web-based platform used to manage Azure services and resources. Through the portal, users can create and manage virtual machines, storage, databases, networks, and security settings. It also allows users to monitor their resources in one place.

##  Four (4) Core Services

| Service |  |
|---|---|
| Azure Virtual Machines | Provides virtual computers that can be used to run applications and other workloads.. |
| Azure Blob Storage | Used to store large amounts of unstructured data such as files, images, and videos. |
| Azure SQL Database | A managed database service that makes it easier to create and maintain relational databases. |
| Microsoft Entra ID | Helps manage user identities and control access to applications and cloud resources. |

## Three (3) Advantages

1. **Microsoft Integration** –Azure works well with Microsoft products such as Windows Server, Microsoft 365, and other Microsoft technologies.
2. **Scalability** – Resources can be increased or decreased depending on the needs of the business.
3. **Enterprise Support** – Azure provides different tools and services that are useful for large businesses and organizations.
##  Typical Enterprise Use Cases

Many companies use Azure for business applications, Windows Server workloads, databases, application development, data analytics, artificial intelligence, backups, and hybrid cloud environments. Azure is also useful for organizations that already use many Microsoft products because it can easily work together with their existing systems..
