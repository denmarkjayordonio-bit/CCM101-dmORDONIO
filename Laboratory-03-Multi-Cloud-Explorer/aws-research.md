# Amazon Web Services

# Brief Overview

Amazon Web Services (AWS) is a cloud computing platform developed by Amazon. It provides different services such as computing, storage, databases, networking, security, and artificial intelligence. With AWS, companies can use these resources through the internet instead of buying and maintaining their own physical servers.

# Global Infrastructure

The AWS Management Console is a website where users can manage their AWS services and resources. Through the console, users can create virtual machines, manage storage and databases, configure networks, and control security settings without needing to use only the command line

#  Cloud Management Console

The AWS Management Console is a web-based interface used to manage AWS services and resources. Users can use the console to create and configure virtual machines, databases, storage, networking resources, security settings, and other cloud services.

# Four Core Services

| Service | Description |
|---|---|
| Amazon EC2  | Provides virtual servers that can be used to run applications and websites. |
| Amazon S3  | Used to store files, images, videos, and other types of data. |
| Amazon RDS  |  Provides managed relational databases, making database management easier. |
| AWS IAM  | Controls users, roles, permissions, and access to AWS resources.|

# Three Advantages

1. Scalability** – AWS resources can be increased or decreased depending on how much an application needs.
2. Global Infrastructure ** –AWS has data centers and cloud infrastructure in different parts of the world.
3. 	Wide Range of Services** – AWS offers a wide variety of services for computing, storage, databases, networking, security, analytics, and AI.

# Typical Enterprise Use Cases

Many businesses use AWS for different purposes, such as hosting websites and applications, storing data, managing databases, creating backups, disaster recovery, running e-commerce systems, analyzing data, and developing AI applications. Because of its many services, AWS can be used by both small businesses and large organizations.
