## 1. Why is object storage better for storing millions of photos?

Object storage is a better option for millions of photos because it is designed to handle large amounts of unstructured data. Photos can be stored as individual objects, making them easier to manage even when the number of files becomes very large.

## 2. How did Docker make MinIO easier to deploy?

Docker made the MinIO setup easier because I did not need to install the storage server manually. I was able to download the image and create the container using Docker commands. I also became more familiar with configuring ports and environment variables.

## 3. What is a bucket?

A bucket is a container used to organize and store objects in an object storage system. In this activity, I created a bucket called `client-photos` where I placed my sample file.

## 4. How can companies protect their object storage data?

Companies can protect their data by keeping backups and multiple copies of important files. They can also use replication and redundant storage so that the data can still be recovered if one server experiences a failure.
