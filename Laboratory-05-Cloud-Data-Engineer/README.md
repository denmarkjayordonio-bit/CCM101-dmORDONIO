## Mission Overview

This laboratory activity focused on cloud storage and the different ways data can be stored. I learned about Block Storage, File Storage, and Object Storage and how each one can be used for different purposes.

For the practical part of the activity, I deployed MinIO using Docker in the KillerCoda Ubuntu environment. I also created a storage bucket and used it to store a sample file.

## Objectives

- Understand the differences between Block, File, and Object Storage.
- Deploy MinIO using Docker.
- Access the MinIO Web Console.
- Create a storage bucket.
- Upload a sample file.
- Practice Linux and Docker commands.
- Document the deployment process.

## Tools Used

- KillerCoda
- Ubuntu Linux
- Docker
- MinIO
- Web Browser
- GitHub

## Activities Completed

During the laboratory, I:

1. Compared the three common types of cloud storage.
2. Downloaded the MinIO Docker image.
3. Created the `minio-server` container.
4. Configured ports `9000` and `9001`.
5. Checked the running container using `docker ps`.
6. Opened the MinIO Web Console.
7. Created the `client-photos` bucket.
8. Uploaded a sample file.
9. Documented the results in GitHub.

## Skills and Knowledge Gained

After completing this laboratory, I gained more experience with Docker and Linux commands. I also learned how Object Storage works and why it is useful for applications that need to store many files.

The activity also gave me hands-on experience deploying a storage service using MinIO instead of only studying the concept theoretically.

## Conclusion

This laboratory helped me understand the practical use of cloud storage. Deploying MinIO with Docker allowed me to see how Object Storage works and how files can be organized using buckets. It also improved my confidence in using Linux and Docker commands.
